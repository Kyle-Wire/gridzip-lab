              extinct

Probes · testing the theory itself

  • Position as storage

    survived

    89.6 KB hidden in word order alone and recovered exactly. Costs the same information as plain bytes; sorting reclaims order that doesn't matter.

  • Experiment 3 · kid → PhD

    survived

    Specialist from day one wins its field; mixed training is the best all-rounder; specializing late forgets. 5 orders × 3 seeds.

    field: specialist 1.945 · mixed 2.279 · kid→PhD 2.442 bits/byte
    fed: topic specialists, curriculum reorder, pretraining

  • Experiment 4 · transformer on grid tokens

    survived

    Same model, same compute: 2.11 bits/byte on grid tokens vs 2.29 on bytes (−7.9%).

  • Batch: compress chunks, recompress

    extinct

    Chunks alone +12%; compressed output doesn't shrink again.

  • The screenshot · two-part code

    extinct for text

    Lowercase layer plus case bits seen with the future. Future context cuts case bits 42%, but the one-pass model already pays less. Suited to images and rasters.
